## 1. 输入资料

统一从一个用户指定目录或明确上传的文件集合读取资料。不要要求用户在开始前选择诊断分支。

优先收集：

- 账号目标、目标用户、当前困扰和运营时间；
- 每周可投入时间、是否出镜、擅长形式和不可执行事项；
- 账号首页截图；
- 笔记列表明细；
- 近30天发布数据；
- 近30天观看或阅读数据；
- 近30天互动数据；
- 近30天涨粉数据；
- 代表性标题、封面、正文或视频文字内容。

资料名称可以不同。根据实际字段判断用途，不依赖固定文件名。

## 2. 文件读取清单

第一轮逐个文件记录：

| 项目 | 要求 |
|---|---|
| 文件名 | 使用本地真实文件名 |
| 文件类型 | Excel、CSV、图片、文本或其他 |
| 工作表/页面 | 列出成功读取的工作表或图片内容 |
| 主要字段 | 只列文件中实际存在的字段 |
| 记录数量 | 能确定时填写 |
| 时间范围 | 使用日期字段或页面标注 |
| 读取状态 | 成功、部分成功、失败 |
| 问题 | 字段缺失、空值、乱码、口径不明或周期冲突 |

不得用“已读取全部资料”替代文件清单。

## 3. 已验证的数据结构

### 账号首页

可包含：

- 账号名称；
- 简介；
- 粉丝数；
- 获赞与收藏等基础数值；
- 置顶内容；
- 主页承接表达。

图片中不可辨认的信息标记为无法确认，不进行猜测。

### 笔记列表明细

优先识别：

- 笔记标题或记录标识；
- 发布日期；
- 内容类型；
- 观看或阅读；
- 点赞、收藏、评论、分享等互动；
- 文件中实际存在的其他表现字段。

不同导出版本字段可能变化。只使用当前文件中真实存在且能解释的数据。

### 近30天趋势资料

已验证的资料类别包括：

- 发布数据；
- 观看数据；
- 互动数据；
- 涨粉数据；
- 平台后台能够提供的其他趋势截图或导出表。

常见分析对象可能包括曝光、观看、封面点击、平均观看时长、完播、互动、主页访问和新增关注。具体定义以文件和页面标注为准。

不要因为指标名称常见就假设文件一定包含该指标。

## 4. 内容样本

只有标题和数据时，可以分析选题与表现差异，但不能对封面、开场、正文或视频内容下强结论。

需要分析内容表达时，补充：

- 高表现和低表现笔记；
- 封面图片；
- 完整标题；
- 图文正文；
- 视频口播文字、字幕或可读取内容；
- 用户认为具有代表性的内容。

将投流、抽奖、活动宣传等异常样本单独标记，不与普通自然流量内容直接混合比较。

## 5. 证据定位

使用：

```text
【证据定位】文件名｜工作表/页面｜行号或记录标识｜字段｜时间范围
```

示例：

```text
【证据定位】近30天涨粉数据.xlsx｜账号趋势｜第18行｜主页访问人数、新增关注人数｜2026-07-01至2026-07-30
```

定位优先级：

1. 文件名；
2. 工作表或图片名称；
3. 行号、笔记标题、发布日期或记录ID；
4. 字段名称；
5. 时间范围。

无法获取准确行号时，至少提供文件名、字段、日期或笔记标题。计算数据时列出公式和参与计算的来源。

## 6. 缺失资料处理

- 缺账号目标：先询问目标，不替用户决定。
- 缺主页资料：不判断主页承接和转粉原因。
- 缺笔记明细：不进行高低表现内容比较。
- 缺趋势资料：只描述现有内容表现，不判断趋势。
- 缺正文或视频内容：不对开场、结构和表达细节下强结论。
- 周期不一致：分别描述，不直接计算跨周期转化。
- 字段定义不明：向用户询问或标记无法判断。

资料不足不等于停止所有分析。缩小能够回答的问题，并降低证据强度。
